# 🎬 CineVerse - Modern Movie & TV Show Explorer

A feature-rich, ultra-modern web application built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion** for discovering and exploring movies and TV shows seamlessly.

---

## ✨ Features

- 🔍 **Real-Time Smart Search:** Debounced search integration allowing users to search shows instantly by title.
- 🏷️ **Interactive Category Bar:** Smooth, scrollable genre filters (Action, Drama, Comedy, Sci-Fi, etc.) with custom UI pills.
- 🎨 **Glassmorphism & Tilt Effects:** Premium 3D tilt cards with dynamic cursor-tracking spotlight glow using Framer Motion.
- ⭐ **Dynamic Rating Rings:** Visual circular progress indicators for show ratings.
- 📱 **Fully Responsive:** Optimized for both mobile devices and large desktop screens.
- ⚡ **Smooth Animations:** Powered by `framer-motion` for fluid page transitions, modals, and layout animations.

---

## 🛠️ Tech Stack

- **Frontend Framework:** React (Vite)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **API Integration:** TVMaze API

## 🚀 Getting Started

Follow these instructions to run the project locally on your machine.

### Prerequisites

Make sure you have **Node.js** (v16 or higher) installed on your system.

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/your-username/movie-explorer.git](https://github.com/your-username/movie-explorer.git)
Navigate to the project directory:

Bash
cd movie-explorer
Install dependencies:

Bash
npm install
Run the development server:

Bash
npm run dev
Open your browser and go to http://localhost:5173 to view the app.
